# 5. PALETTE PRINCIPALE

## 5.1 Couleur primaire

**Violet Speakora**

```text
#6D5CFF
```

### Utilisation

Cette couleur constitue la couleur principale de Speakora.

Elle doit être utilisée notamment pour :

- boutons principaux ;
- liens actifs ;
- éléments interactifs ;
- icônes importantes ;
- progression ;
- badges ;
- accents visuels ;
- certains titres ;
- éléments de navigation actifs.

---

# 6. COULEUR SECONDAIRE

**Mauve Speakora**

```text
#A855F7
```

### Utilisation

Elle complète la couleur primaire.

Elle peut être utilisée pour :

- dégradés ;
- éléments décoratifs ;
- variantes de boutons ;
- icônes ;
- badges ;
- illustrations ;
- accents graphiques.

---

# 7. DÉGRADÉ PRINCIPAL

Le dégradé principal recommandé est :

```text
#6D5CFF → #A855F7
```

Ce dégradé peut être utilisé sur :

- boutons principaux ;
- grandes zones Hero ;
- badges premium ;
- barres de progression ;
- icône ou logo si pertinent ;
- éléments promotionnels ;
- affiches.

Le dégradé ne doit pas être utilisé excessivement.

---

# 8. COULEUR D’ACCENT

**Orange / Doré**

```text
#F59E0B
```

Cette couleur sert à attirer ponctuellement l’attention.

### Utilisation recommandée

- récompenses ;
- trophées ;
- XP spéciaux ;
- éléments premium ;
- étoiles ;
- badges ;
- séries ;
- notifications importantes non critiques.

# 9. COULEUR DE SUCCÈS

- sauvegarde effectuée ;

# 10. COULEUR D’ERREUR

**Rouge**

# 14. BOUTONS

## Bouton principal

Le bouton principal doit utiliser :

- le violet `#6D5CFF` ;
- ou le dégradé `#6D5CFF → #A855F7`.

### Exemple

**Commencer**

### Caractéristiques

- coins arrondis ;
- texte blanc ;
- contraste élevé ;
- aspect premium ;
- hauteur confortable sur mobile ;
- animation légère au survol ou au toucher.

---

## Bouton secondaire

Le bouton secondaire peut utiliser :

- un fond violet très clair ;
- un contour violet ;
- un texte violet.

Il ne doit pas avoir plus d’importance visuelle que le bouton principal.

---

## Bouton succès

Utiliser :

```text
#10B981
```

Exemple :

**Leçon terminée**

---

## Bouton erreur ou action destructive

Utiliser :

```text
#EF4444
```

Exemples :

- Réinitialiser
- Supprimer
- Recommencer après erreur si nécessaire

---

# 15. BARRES DE PROGRESSION

Les barres de progression peuvent utiliser :

```text
#6D5CFF
```

ou le dégradé :

```text
#6D5CFF → #A855F7
```

Le fond de la barre doit être discret.

La progression doit rester facilement lisible en thème clair comme en thème sombre.

# 17. BADGES

Les badges peuvent être utilisés pour :

- niveaux ;
- statut ;
- XP ;
- série ;
- progression ;
- catégorie pédagogique.

Les couleurs des badges doivent respecter la hiérarchie générale.

# 18. NIVEAUX

Les niveaux peuvent disposer de couleurs secondaires propres afin d’améliorer leur différenciation.

Cependant, ces couleurs doivent rester compatibles avec l’identité générale Speakora.

Le violet doit rester dominant dans l’application globale.

---

# 19. SUCCÈS ET RÉCOMPENSES

Pour les récompenses :

- vert pour la réussite ;
- orange/doré pour les étoiles, trophées et récompenses ;
- violet pour la progression principale.

Exemple :

```text
Bonne réponse     → #10B981
XP / récompense   → #F59E0B
Progression       → #6D5CFF
```

---

# 20. ERREURS

Les erreurs doivent être clairement identifiables sans être agressives.

Couleur principale :

```text
#EF4444
```

Il est recommandé d’utiliser également :

- une icône ;
- un texte explicatif ;
- un fond rouge très léger.

La couleur seule ne doit jamais constituer l’unique indication d’une erreur.

---

La typographie de Speakora doit être :

- moderne ;
- lisible ;
- arrondie sans excès ;
- adaptée au mobile ;

Exemples possibles :

- Poppins ;
- Inter ;
- Manrope ;
- Outfit.


---

# 35. COHÉRENCE

Aucune nouvelle couleur principale ne doit être ajoutée au projet sans justification.

Toute nouvelle couleur doit avoir une fonction claire.

Exemple :

- violet = marque / action ;
- mauve = complément ;
- vert = succès ;
- rouge = erreur ;
- orange = récompense ;
- gris = information secondaire.

---

# 36. À ÉVITER

Ne pas utiliser :

- trop de couleurs simultanément ;
- plusieurs types de dégradés sans cohérence ;
- des boutons principaux de couleurs différentes selon les pages ;
- des fonds trop chargés ;
- des ombres excessives ;
- des animations agressives ;
- des couleurs trop saturées en grande quantité ;
- des textes à faible contraste.

---

# 37. VARIABLES CSS RECOMMANDÉES

La palette pourra être centralisée dans le projet avec des variables CSS.

Exemple :

```css
:root {
  --color-primary: #6D5CFF;
  --color-secondary: #A855F7;
  --color-accent: #F59E0B;
  --color-success: #10B981;
  --color-error: #EF4444;

  --color-bg: #F5F7FB;
  --color-card: #FFFFFF;

  --color-text: #111827;
  --color-text-secondary: #6B7280;

  --color-dark-bg: #0D1020;
  --color-dark-card: #171C30;
}
```

Cela permettra de maintenir facilement la cohérence graphique.
